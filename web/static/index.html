2~5 人探险，满 5 人自动开始，房主也可以提前开始；等待时房主可添加机器人

            
          

          

        


        

          
规则速览

          
    
            
  1. 每轮先自动翻开一张牌，随后每位在场玩家依次决定「继续」或「下车」。
    2. 
            
  2. 点棒牌：在场玩家平分点数，除不尽的余数留在池中。
    3. 
            
  3. 役满牌：进入役满池，留在原地等最后下车的人带走。
    4. 
            
  4. 陷阱牌：第二次翻到同一张陷阱时本轮立即结束，在场玩家丢失本轮累积。
    5. 
            
  5. 下车：先结算。独自下车可带走本轮携带 + 点棒池 + 役满池；多人同时下车只平分点棒池，役满留在原地。
    6. 
            
  6. 所有人下车、牌堆翻完或触发陷阱都会结束本轮；共 5 轮，每轮新增一张役满牌。
